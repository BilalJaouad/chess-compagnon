# Signaler une vulnérabilité

Utilise **Security → Report a vulnerability** sur GitHub pour transmettre un signalement privé. Décris le composant affecté, les étapes de reproduction et l’impact attendu, en utilisant des données fictives.

Ne publie pas de secret, cookie, jeton d’accès ou donnée de compte dans une issue publique. Si un secret a été exposé, révoque-le auprès du service concerné avant de partager des éléments de diagnostic.

Le projet est maintenu sur une base communautaire ; aucun délai de réponse n’est garanti.
