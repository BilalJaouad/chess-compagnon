How to interpret the results
  • Set detectorFeedbackAvailable to false and firstFlagGame to null when you only observe bans.
  • A run stopped after six games with no ban is unresolved for a ten-game tournament.
  • Human-control rows measure false-positive outcomes only if the control labels are reliable.
  • Intervals assume independent observations. Team members playing each other may violate that assumption.
  • Missing-outcome bounds include unresolved runs and are not confidence intervals.
Input format
Use pseudonymous IDs, one run per participant. Null means no recorded event through observedGames; with no detector feedback, a null flag means unknown.
